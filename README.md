# OneSync Landing Page & Documentation Site

This branch (`landing-page`) hosts the static website showcasing the **OneSync** macOS Apple Silicon desktop application.

Crafted using plain HTML5, vanilla CSS3, and JavaScript, strictly adhering to the **sibansal · Dark Teal Theme** extracted from [`sibansal/portfolio`](https://github.com/sibansal/portfolio).

## Pages

- [`index.html`](index.html): Main landing page with feature breakdown, interactive screenshot showcase, architecture breakdown, and download CTAs.
- [`terms.html`](terms.html): Standalone Terms of Service page.
- [`privacy.html`](privacy.html): Standalone Privacy Statement detailing zero telemetry and client-side encryption.
- [`license.html`](license.html): Standalone MIT License page.

## Assets

- `assets/icon.png`: High-resolution OneSync application icon.
- `assets/screenshot-connect.png`: High-resolution screenshot of the initial OneDrive connection flow.
- `assets/screenshot-dashboard.png`: High-resolution screenshot of the live sync dashboard and console.
